Mang đến một nền tảng thực hành **Web3 Trong Sáng (100% Testnet - Không dùng tiền thật)**, nơi người dùng học hỏi bản chất cốt lõi của công nghệ sổ cái phân tán thông qua việc đóng dấu chứng nhận cây xanh, nhận token sinh thái `$tGREEN` và hiểu về tính minh bạch bảo vệ môi trường.

## 2. ĐÁNH GIÁ TOÀN DIỆN TỪ HỘI ĐỒNG 5 CHUYÊN GIA

### 2.1. Chuyên gia Lâm nghiệp & Phục hồi Sinh thái
* **Trọng tâm là Giữ rừng và Sinh khối:** Giá trị của trồng rừng nằm ở **Tỷ lệ sống sót ($S_r\%$)** sau các chu kỳ 6, 12, 24, 36 tháng. Hệ thống phải theo dõi sinh trắc học cơ bản: Chiều cao vút ngọn ($H_{vn}$), đường kính gốc ($D_0$), độ khép tán và cơ cấu cây gỗ lớn bản địa (Sao đen, Dầu rái, Lim xanh, Đước đôi, Tràm gió).
* **Tuân thủ Luật Lâm nghiệp 2017:** Phân định rõ 3 loại rừng (Đặc dụng, Phòng hộ, Sản xuất) để áp dụng quy chế tiếp cận và giám sát phù hợp.
* **Tích hợp Khoa học Dân sự (Citizen Science):** Bổ sung việc ghi nhận đa dạng sinh học (hoa rừng, nấm lạ, dấu vết muông thú) để xây dựng bản đồ sinh thái phong phú mà không cần đoàn nghiên cứu tốn kém.

### 2.2. Chuyên gia Thiết kế Kiến trúc Phần mềm
* **Nền tảng 100% Web (Web-First, No Native App):** Loại bỏ gánh nặng cài đặt app. Sử dụng công nghệ **PWA (Progressive Web App)** trên nền React 18 + Vite + Tailwind CSS.
* **Cơ chế Kép (Dual-Mode Engine):**
  * *Online Real-time (Đón đầu Internet Vệ tinh):* Sử dụng kết nối Starlink Direct-to-Cell / 4G biên giới để băm hash và đóng dấu khối Testnet ngay lập tức dưới tán rừng già.
  * *Offline-first (Khi tạm thời mất sóng):* Công nghệ Service Worker và IndexedDB lưu trữ cục bộ, tự động kích hoạt `Background Sync API` khi thiết bị bắt lại sóng.
* **Multi-chain Adapter Pattern:** Thiết kế tầng trừu tượng tại Backend PHP 8.3 PDO, cho phép chuyển đổi mượt mà giữa Cardano, Polygon và Celo mà không sửa đổi logic lâm nghiệp.
* **Merkle Tree Batching Engine:** Gom nhóm 50–100 quan sát thực địa thành một Merkle Root duy nhất trước khi ghi on-chain, tối ưu hóa 98% tài nguyên mạng Testnet.

### 2.3. Chuyên gia Công nghệ Blockchain & ReFi
* **Cardano Preprod Testnet (Nền tảng Cốt lõi):** Tận dụng kiến trúc eUTXO và Metadata giao dịch (CIP-20 / CIP-25) để lưu trữ bằng chứng trồng rừng với chi phí cực thấp, bảo mật tuyệt đối, kế thừa trực tiếp bài học của Veritree & BlockTree.
* **Polygon Amoy & Celo Alfajores Testnets (Mở rộng EVM):** Phát hành đồng Token Sinh Thái `$tGREEN` theo chuẩn ERC-20 và Chứng chỉ Bảo trợ Rừng theo chuẩn Soulbound Token (ERC-5192 phi chuyển nhượng).
* **Mô hình Ví Khách Thể Nhẹ Nhàng (Custodial Vault to Self-Custody):** Người dùng bình thường không cần ví Web3 vẫn có "Ví Xanh nội bộ" trên website; người dùng nâng cao có thể tự do rút token `$tGREEN` về ví cá nhân (Lace, MetaMask) để trải nghiệm quyền sở hữu phi tập trung thực sự.

### 2.4. Chuyên gia Thiết kế Trải nghiệm Người dùng (UI/UX)
* **Giao diện Thực địa "Một Tay" (One-Hand Field Interaction):** Các nút bấm chức năng to bản ở 1/3 dưới màn hình, dễ dàng bấm bằng ngón cái khi đang cầm gậy trekking.
* **Chế độ Chống Chói Nắng Gắt (Sun Glare High-Contrast Mode):** Màu sắc tương phản cao, tối ưu hiển thị ngoài trời nắng.
* **Tuyệt đối Không Dùng Thuật Ngữ Web3 Rối Rắm:** Thay các từ "Mint, Hash, eUTXO, Gas" bằng "Đóng dấu Mộc Xanh, Mã kiểm chứng bất biến, Điểm danh dự sinh thái".
* **Kính Lúp Blockchain Trực Quan:** Bấm vào bất kỳ chứng chỉ nào để xem đồ họa mô phỏng: Ảnh $\rightarrow$ Mã băm $\rightarrow$ Khối Testnet $\rightarrow$ Cardanoscan/Polygonscan.

### 2.5. Chuyên gia An ninh mạng & Bảo vệ Bí mật Quốc gia
* **QUY TẮC AN NINH QUỐC PHÒNG TUYỆT ĐỐI:** Tuyệt đối KHÔNG lưu trữ và KHÔNG công khai tọa độ GPS điểm (kinh độ/vĩ độ thập phân). Toàn bộ rừng được quản lý theo **Địa danh hành chính dân sự (Xã/Huyện/Tỉnh) + Mã hiệu Cột mốc thực địa (Landmark Post Code) công khai**.
* **Bảo vệ Động Thực Vật Nguy Cấp (Sách Đỏ):** Thông tin phát hiện loài quý hiếm không bao giờ hiển thị vị trí chi tiết, chỉ thông báo nội bộ cho Ban Quản lý Vườn quốc gia để phục vụ bảo tồn, triệt tiêu nguy cơ tiếp tay cho lâm tặc và săn trộm.
* **Chống Giả Mạo Ảnh (Image Forensics):** Phân tích cấu trúc pixel và nhiễu cảm biến camera để loại trừ ảnh tải từ mạng hoặc ảnh chụp lại màn hình điện thoại khác; giới hạn tần suất 1 check-in/lô/ngày.

## 4. THIẾT KẾ CƠ SỞ DỮ LIỆU ĐỒNG BỘ (MYSQL DDL)

Cơ sở dữ liệu được tích hợp hoàn toàn vào backend PHP hiện có, khớp với các Móc nối kỹ thuật cốt lõi (H1: User UUID, H7: SHA-256 ảnh, H8: Không lưu GPS nhạy cảm, H12: Feature flag).

```sql
-- ====================================================================
-- 1. DANH MỤC DỰ ÁN RỪNG & VƯỜN QUỐC GIA
-- ====================================================================
CREATE TABLE IF NOT EXISTS `forestry_projects` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `code` VARCHAR(50) UNIQUE NOT NULL, -- e.g. 'VN-BIDOUP-01'
  `name` VARCHAR(255) NOT NULL,
  `slug` VARCHAR(255) UNIQUE NOT NULL,
  `province` VARCHAR(100) NOT NULL,
  `district` VARCHAR(100) NOT NULL,
  `forest_category` ENUM('special_use', 'protection', 'production') NOT NULL DEFAULT 'protection',
  `total_area_ha` DECIMAL(8, 2) NOT NULL DEFAULT 0.00,
  `target_tree_count` INT NOT NULL DEFAULT 0,
  `planted_tree_count` INT NOT NULL DEFAULT 0,
  `managing_entity` VARCHAR(255) NOT NULL,
  `description` TEXT NULL,
  `is_active` TINYINT(1) DEFAULT 1,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ====================================================================
-- 2. LÔ RỪNG & ĐỢT TRỒNG CÂY (TUYỆT ĐỐI KHÔNG LƯU GPS ĐIỂM)
-- ====================================================================
CREATE TABLE IF NOT EXISTS `forestry_batches` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `batch_code` VARCHAR(64) UNIQUE NOT NULL, -- e.g. 'BATCH-2026-BIDOUP-SAODEN'
  `project_id` INT NOT NULL,
  `species_scientific_name` VARCHAR(255) NOT NULL,
  `species_common_name` VARCHAR(255) NOT NULL,
  `is_red_list` TINYINT(1) DEFAULT 0,
  `tree_quantity` INT NOT NULL,
  `planting_date` DATE NOT NULL,
  `zone_designation` VARCHAR(150) NOT NULL, -- Phân khu dân sự/tiểu khu lâm nghiệp
  `landmark_post_code` VARCHAR(100) NOT NULL, -- e.g. 'COT-MOC-KM14', 'TRAM-DUNG-02'
  `initial_evidence_image_hash` CHAR(64) NOT NULL,
  `status` ENUM('registered', 'planted', 'verifying', 'certified_onchain') DEFAULT 'registered',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`project_id`) REFERENCES `forestry_projects`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ====================================================================
-- 3. BÁO CÁO GIÁM SÁT CHU KỲ dMRV (TỶ LỆ SỐNG & SINH KHỐI)
-- ====================================================================
CREATE TABLE IF NOT EXISTS `forestry_dmrv_audits` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `batch_id` INT NOT NULL,
  `audit_milestone_months` INT NOT NULL, -- 3, 6, 12, 24, 36 tháng
  `inspection_date` DATE NOT NULL,
  `survival_rate_percent` DECIMAL(5, 2) NOT NULL, -- e.g. 91.50%
  `average_height_cm` INT NULL,
  `canopy_coverage_percent` DECIMAL(5, 2) NULL,
  `estimated_co2e_tons` DECIMAL(10, 3) DEFAULT 0.000,
  `health_rating` ENUM('excellent', 'good', 'fair', 'critical') DEFAULT 'good',
  `auditor_name` VARCHAR(150) NOT NULL,
  `audit_image_hash` CHAR(64) NOT NULL,
  `notes` TEXT NULL,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`batch_id`) REFERENCES `forestry_batches`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ====================================================================
-- 4. KHOẢNH KHẮC RỪNG XANH & CHECK-IN CỘNG ĐỒNG (TREKKER MOMENTS)
-- ====================================================================
CREATE TABLE IF NOT EXISTS `nature_moments` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `batch_id` INT NULL,
  `user_uuid` CHAR(36) NOT NULL,
  `trail_name` VARCHAR(150) NOT NULL,
  `landmark_post_code` VARCHAR(100) NOT NULL,
  `moment_type` ENUM('tree_inspection', 'scenic_view', 'rare_flora', 'wildlife_track', 'trail_tip') NOT NULL,
  `title` VARCHAR(255) NOT NULL,
  `caption` TEXT NULL,
  `image_sha256` CHAR(64) NOT NULL,
  `is_realtime_satellite` TINYINT(1) DEFAULT 0,
  `community_upvotes` INT DEFAULT 0,
  `tgreen_rewarded` DECIMAL(8, 2) DEFAULT 0.00,
  `onchain_postcard_tx` VARCHAR(128) NULL,
  `status` ENUM('published', 'flagged', 'hidden') DEFAULT 'published',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ====================================================================
-- 5. SỐ DƯ & LỊCH SỬ THƯỞNG TOKEN TESTNET ($tGREEN)
-- ====================================================================
CREATE TABLE IF NOT EXISTS `user_token_balances` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `user_uuid` CHAR(36) UNIQUE NOT NULL,
  `internal_balance` DECIMAL(12, 2) DEFAULT 0.00,
  `withdrawn_balance` DECIMAL(12, 2) DEFAULT 0.00,
  `external_wallet_address` VARCHAR(255) NULL,
  `network_preference` ENUM('cardano_preprod', 'polygon_amoy') DEFAULT 'cardano_preprod',
  `updated_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS `token_transactions` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `user_uuid` CHAR(36) NOT NULL,
  `tx_type` ENUM('reward_checkin', 'reward_moment', 'reward_quiz', 'mint_postcard', 'donate_forest', 'withdraw_external') NOT NULL,
  `amount` DECIMAL(12, 2) NOT NULL,
  `onchain_tx_hash` VARCHAR(128) NULL,
  `description` VARCHAR(255) NOT NULL,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ====================================================================
-- 6. SỔ CÁI BẢNG GIAO DỊCH BLOCKCHAIN TESTNET ĐA CHUỖI
-- ====================================================================
CREATE TABLE IF NOT EXISTS `blockchain_record_ledger` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `entity_type` ENUM('batch_mint', 'dmrv_audit', 'trekker_merkle_batch', 'nature_postcard', 'token_airdrop') NOT NULL,
  `entity_id` INT NOT NULL,
  `network` ENUM('cardano_preprod', 'polygon_amoy', 'celo_alfajores') NOT NULL,
  `tx_hash` VARCHAR(128) NOT NULL,
  `policy_or_contract_address` VARCHAR(128) NULL,
  `token_id` VARCHAR(128) NULL,
  `explorer_url` VARCHAR(500) NOT NULL,
  `payload_metadata_json` TEXT NOT NULL,
  `status` ENUM('submitted', 'confirmed', 'failed') DEFAULT 'confirmed',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 5. CƠ CHẾ ĐA CHUỖI & THIẾT KẾ ĐỒNG TOKEN SINH THÁI ($tGREEN)
